# Data

Files copied from the ProteusData repository (https://github.com/UH-DAIS/ProteusData):

| File | Content |
|---|---|
| `edge_verification_results_raw_downtown.csv` | Published raw results of the edge-verification parameter study, Downtown Houston (2160 parameter combinations x 2/3/5-edge accuracy). |
| `edge_verification_results_raw_UH.csv` | Same for the University of Houston campus. |
| `houston_downtown_map_gen.csv` | Edge list (`x0,y0,x1,y1`, lon/lat) of a map generated by Proteus for Downtown Houston. |
| `university_map_gen.csv` | Same for the University of Houston campus. |

The two `*_map_gen.csv` files are used here as stand-in road networks with the real
geometry of the two study areas when OpenStreetMap (OSMnx) is not reachable. They are
Proteus *outputs*, so they are fragmented (hundreds of connected components) and are not
the pre-disaster ground truth used in the paper; pass `--osm` to the reproduction script
to download the original OSM networks instead.
